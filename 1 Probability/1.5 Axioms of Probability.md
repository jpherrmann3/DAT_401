# 1.5 Axioms of Probability

- We would like event event to be conisdered as a subset of the set of all possible outcomes $S$ called the sample space.
- The probability should be a function $E \rightarrow P(E)$, assigning to each event $E$ some number between 0 and 1.
- For $E = S$, we want $P(S)=1$.
- Also, in order to be able to calculate probabilities of events that can be decomposed into simpler disjoint events, we want probability function to be "countable additive" (see Axiom 3 below).

After hundreds of years of experience, it turns out htese requirements are sufficient to cover all situations that appear in practice, and to derive all the properties we would intuatively expect fomr probability. We now state them in forms of axioms.

If $E$ is a collection of subsets (called events) aof set $S$ (called sample space), any real-valued function $P$ with domain $E$ is called **probability**, if its satisfies the following conditions/axioms:

**Axiom 1**. For any event $E$,

$$
0 \le P(E) \le 1
$$

**Axioma 2**.

$$
P(S) = 1
$$

**Axioma 3.**

For any countable sequence of mutually exclusive events $E_1, E_2, \ldots$ (that is, events for which $E_i \cap E_j = \emptyset$ whenever $i \neq j$),

$$
P \left( \bigcup_{i=1}^\infty E_i \right) = \sum_{i =1}^\infty P(E_i)
$$

**Notation and Convention**

- We refer to $P(E)$ as the probability of event $E$.
- To emphasize that $\bigcup_{i=1}^\infty E_i$ is union of **disjoint** sets, we often right it as $\bigcup_{i=1}^{\underset{\cdot}{\infty}}E_i$, or $\biguplus_{i=1}^{\infty} E_i$ (suggesting we can apply countable additivity axiom to the particular sequents of events).
- Unless otherwise stated, capital letter $S$ will be used for the sample space. Capital letter $P$ will be reserved for probability as a set function. Events will typically be denoted by capital letters: $A, B, C,\ldots$
- Also, the intersection $A \cap B$ of two events $A$ and $B$ will often be written shortly as $AB$. So $P(AB)$ would represent the probability that both events $A$ and $B$ happen.

Question: Why is there need for countably many (pair-wise disjoint) events in Axiom 3?

It turns out there are situations in practice where finite disjoint unions are not sufficient, and where certain events could only be analyzed by thinking of them as countable unions. Before we see such examples, we first showt hat some properties of probability that are intuitively expected and natural in certain problems, can indeeded be derived from the three axioms we have.

**Example**

Suppose we case a die. The sample space is $S = \{1, 2, 3, 4, 5, 6\}$. Denote $A=\{5\}$ and $B=\{6\}$. Then $A \cap B = \emptyset$. Intuitively, for the probability of $A \overset{\cdot}{\cup} B=\{5, 6\}$, we have

$$
P(A \overset{\cdot}{\cup} B) = P(\{5, 6\}) = \frac{|\{5, 6\}|}{|S|} = \frac{2}{6} = \frac{1}{6} + \frac{1}{6} = \frac{|A|}{|S|} + \frac{|B|}{|S|} = P(A) + P(B)
$$

This is actually in accordance with the Axioma 3. Namely, we can write

$$
A \overset{\cdot}{\cup} B = A \overset{\cdot}{\cup} B \overset{\cdot}{\cup} \emptyset \overset{\cdot}{\cup} \emptyset \overset{\cdot}{\cup} \ldots
$$

Then, applying Axiom 3 for pair-wise disjoint events $E_1 = A, E_2 = B, E_3 = E_4 = \ldots = \emptyset$, we get

$$
P(A \overset{\cdot}{\cup} B) = P \left( \bigcup_{i=1}^\infty E_i \right) = \sum_{i=1}^\infty P(E_i) = P(A) + P(B) + 0 + 0 + \ldots = P(A) + P(B)
$$

It must be that $P(\emptyset)=0$ for otherwise, the series on the right-hadn side of the above equality would diverge towards infinity, which would violate Axiom 1, according to which $P(A \overset{\cdot}{\cup} B)$ must be less than or equal to 1.

So, we see taht

$$
P(\emptyset) = 0
$$

and plugging this in into (1.1), we also get

$$
P(A \overset{\cdot}{\cup} B) = P(A) + P(B)
$$

Note that the identity (1.3) holds for any two disjoint events A and B, since in the above arguemetn we haven't used anything specific about $A$ and $B$, other than the fact that they are disjoint.

Expanding further the argument above, if $E_1, E_2, \ldots, E_n$ are pairwise disjoin events of sample space $S$, then

$$
E_1 \overset{\cdot}{\cup} E_2 \overset{\cdot}{\cup} \ldots \overset{\cdot}{\cup} E_n = \bigcup_{i=1}^n E_i = \bigcup_{i=1}^n E_i \overset{\cdot}{\cup} \emptyset \overset{\cdot}{\cup} \emptyset \overset{\cdot}{\cup} \ldots
$$

and using the Axioma 3 and (1.2), we conclude:

$$
P \left( \bigcup_{i=1}^n E_i \right) = \sum_{i=1}^n P(E_i)
$$

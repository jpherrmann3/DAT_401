# Ch 1 Probability

Many problems in Data Science involve models that are of stochastic, i.e. random nature. In this and the following chapters we will study various aspects of randomness and quantify certainty. Fundamental notions here are:

- **Experiment** (i.e. **trial**) - any procedure that could hypothetically be repeated as many times we want, always under the same conditions/circumstances.
- **Elementary outcome** - a single possible result of the experiment.
- **Sample space** - the set of all possible outcomes (we will denote it by $S$).
- **Event** - a collection of possible outcomes (so, a subset of $S$).
- **Probability** - a quantification of the level of certainty about an event of interest.

## Example 1.1

Experiment: Casting a die.

Outcomes: &#127922; 1, 2, 3, 4, 5, 6.

So the sample space is: $S = \{1, 2, 3, 4, 5, 6\}$.

Examples of events:

**A** - event that even number appears; $A = \{2, 4, 6\}$.

**B** - event of getting at least 2; $B = \{2, 3, 4, 5, 6\}$.

Probability of event $A$: $P(A) = \frac{3}{6} = \frac{1}{2}$.

Probability of event $B$: $P(B) = \frac{5}{6}$.
